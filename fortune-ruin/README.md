# 夜色筹码：Fortune & Ruin

一款 2D 俯视角开放世界「赌场人生」模拟游戏。你住在港口城市 **灰港（Greyhaven）**，可以上班、租房买房、交朋友、投资，也可以走进灰港大赌场，在完全按照公开规则运行的牌桌上下注——然后亲身体会财富的起伏如何改变你的生活，以及别人看你的眼光。

> **所有赌注、筹码与财富均为纯虚拟游戏货币。** 本游戏不提供任何真钱投注、充值、兑换或提现，游戏内容不构成任何投资或博彩建议。

## 快速开始

需要 Node.js 18+（开发时使用 Node 22）。在仓库根目录或 `fortune-ruin/` 目录下执行：

```bash
npm install
npm run dev        # 启动开发服务器，浏览器打开 http://localhost:5173
npm test           # 运行全部单元测试（Vitest）
npm run build      # 类型检查 + 生产构建，输出到 fortune-ruin/dist
npm run preview    # 预览生产构建
```

游戏完全离线运行，没有任何外部资源请求，也不依赖付费 AI 服务：像素美术在运行时由代码生成；配乐是为本游戏原创的 17 首循环曲目（随游戏打包的音频文件，作曲与渲染流程见 [tools/music](tools/music/README.md)）。界面和游戏内文字使用随游戏打包的像素字体「缝合像素字体」（SIL OFL 1.1，见 [src/ui/fonts](src/ui/fonts/README.md)）。

### 单文件版（不用安装任何东西）

```bash
npm run build:single   # 输出 fortune-ruin/dist-single/fortune-ruin.html（约 50 MB，大部分是 Base64 编码的配乐）
```

这个 HTML 文件包含了整个游戏（代码、Phaser、React、样式和配乐）。把它复制到任何电脑上，用 Chrome / Edge / Firefox / Safari 双击打开就能玩，不需要 Node.js、不需要联网。存档保存在这台电脑的浏览器里；换电脑或换浏览器时，先在游戏的存档界面「导出」存档文件，再到新地方「导入」。

## 开局

创建角色时可以选：名字、称呼（他 / 她 / TA）与体型、6 种肤色、12 种发色、12 种发型（短发、侧分、长直发、波波头、马尾、盘发、卷发、背头、寸头、长波浪、光头、长卷发）、4 种眼型与 6 种瞳色、眼镜 / 胡子 / 耳环、帽子（毛线帽、鸭舌帽）、三套初始衣着和 8 种上衣颜色，会对谁动心（女性 / 男性 / 不限 / 暂不考虑），以及性格倾向和出身背景。左侧同时预览半身像（可切换表情）和小人（可转向）。

开局有四种起点，**之后的一切概率都一样**——有钱只是让你摔得更久：

| 开局 | 住处 | 工作 | 钱 |
| --- | --- | --- | --- |
| 普通的一天 | 老城区出租公寓（月租 1,450 G） | 灰港物流行政文员（9:00–17:00，月薪 4,400 G） | 现金 1,000 G，存款 19,000 G |
| 彩票头奖 | 同上 | 同上 | 存款多出 800,000 G；熟人都听说了，以为你有一百万 |
| 套现离场 | 自有的河畔塔楼 28F | 没有 | 现金 5,000 G，存款 1,200,000 G，300,000 G 指数基金；理财与工作技能更高，投资顾问索菲亚是你的熟人，赌场 Silver 会员 |
| 含着金汤匙 | 自有的天际顶层公寓 | 没有 | 现金 20,000 G，存款 3,000,000 G；一辆跑车、西装与晚礼服，赌场 Gold 会员，客户经理维克多和航运继承人亚历山大都认识你 |

有房有车的开局没有房租，但物业费、跑车的保养保险每月照常扣款。

普通开局时你在第 1 年 3 月 1 日（星期一）早上 7 点于老城区的枫庭公寓醒来：几位朋友（发小丹尼尔、咖啡师艾琳、房东玛格丽特……）、灰港大赌场的普通访客会员卡，手机里有朋友的消息、上司的会议提醒和银行的账户概览（「大学毕业生」背景还带一笔助学贷款）。

开场会先弹出一张「清晨简报」：你在哪里上班、几点要到、从家走过去多久、迟到和缺勤的后果（没有工作的开局则说明你的处境）。之后屏幕左上角一直显示下一班的时间（上班前一个半小时变黄、迟到后变红，点击它会在地图上标出公司），上班前 1 小时和 15 分钟、以及迟到时都会有提醒——人已经在公司或正在睡觉时不提醒。

### 城市与世界
- 120×90 格的灰港城市地图：老城区、集市街、市中心、联合广场、河滨公园与步道、码头、河上的游艇会浮动码头、去白石湾的渡轮码头、山丘富人区，带门禁的富人区入口；29 栋有外立面的建筑。坐渡轮可以到海湾对面 72×48 格的白石湾（渔港、渔村、灯塔岬、公共海滩和度假酒店，6 栋建筑）。
- 25 个可进入的室内场景：6 档住宅（码头合租房 → 山丘庄园）、便利店、咖啡馆、餐厅、酒吧、服装店、银行、办公室、投资公司、私人会所、米其林餐厅、奢侈品店、车行、灰港大酒店、老城区的当铺和社区食堂、灰港大赌场，以及白石湾的老船长食堂、海鸥民宿和白石湾度假酒店。
- 玩家角色移动（键盘 / 点击寻路）、碰撞与转角辅助、门与场景切换（带营业时间、会员、预订、着装、员工等进入条件）。
- 进出建筑时人是走进门去的：街上的门先打开，露出里面昏暗的门廊（晚上透着灯光），你迈步进去、身影没入门里，画面再暗下去；到了里面，你从门口的地垫上走进来。出门时反过来：你从门口走出去，到了街上是从敞开的门里迈出来，身后的门随后关上。打车、坐公交、乘电梯等其他出行仍是各自的过场或淡入淡出。
- 昼夜系统：日出日落随季节变化，夜间路灯光圈、亮灯的窗户与霓虹，室内各自的照明。
- 光影与质感：光线统一从左上方来。室内地面在墙根处变暗，家具脚下有接触阴影（美术里已画了阴影的道具不重复加），白天窗户在地板上投下斜向的光斑；城市里的建筑向东投下随楼高变长的影子，楼脚有一圈阴影，影子和窗光随日照淡入淡出。建筑立面的檐口下、遮阳篷下有阴影，窗玻璃退在墙面里，转角一侧受光一侧背光。大理石地面按 2×2 的整块石板铺设（每块的纹理不同），木地板、人行道、路面和水泥地有多种变体（偶尔的污渍、裂缝、下沉的石板），不再每 16 像素重复一次。
- 屋顶：平屋顶按楼的用途铺成不同的样子。仓库、车行和渡轮大厅是波纹金属板；小店和餐馆是压着卵石的防水层，留一条检修走道；灰港大酒店、度假酒店、法餐厅和奢侈品店是铺石板的露台，沿女儿墙一排花槽，酒店和度假酒店的木平台上有泳池、躺椅和遮阳伞，法餐厅和奢侈品店的木平台上是遮阳伞和椅子；公寓楼顶有住户的种植箱（生菜、番茄、西葫芦、香草），住宅楼顶挂着晾衣绳。女儿墙有压顶石和排水口，墙在屋面上投下阴影，旧屋面上留着积水干后的水渍；大楼顶上有机房和风管、空调外机、通风口、电视天线和卫星锅。屋顶只是画面，上不去。
- 街上的行人与车流（车辆会为行人停下），公交站（06:00–24:00）、出租车与私家车 / 自行车出行。

### 老城区与码头：城市的另一面

山丘区有私人会所和米其林餐厅，老城区有当铺、免费食堂和码头的零工。穷和富用的是同一座城市里的不同地方，在两边都能做真实的事。

- **福来当铺**（老城区，每天营业）：首饰、手表、贵重礼品、正装和车都可以拿来典当。按估价（转卖价）的六成借给你现金，单笔最多 8 万 G；30 天当期，每满 10 天收借款 3% 的综合费（一年下来超过借款本身）。期内连本带费赎回，或者付清已产生的费用续当；到期后再宽限 10 天，仍不赎回就成为绝当品，东西摆上店里的二手柜台。到期前 3 天和宽限期结束前 2 天，当铺会发短信提醒。也可以直接卖断（车按估价的八五折）。二手柜台每周一按种子换一批货（八折到四五折不等的手表、首饰、西装、自行车、吉他），你当掉没赎、卖掉的东西也会以加价后的价格摆在那里，可以再买回来。当着的东西按「估价 − 赎回所需」计入净资产。贵重物品不再能在背包里随处变卖，要拿到当铺去。有熟人在店里看见你当东西，会记住、会说出去，见面时也会提起。
- **海员之家社区食堂**（老城区，每天 11:00–14:00、17:00–20:00）：每人每天一份免费热饭；可以在开饭时间帮忙打两个小时饭菜（心情、压力、社交都会好起来，在场的人会记住），也可以捐款（现金或刷卡，名字写上墙上的捐赠板，和航运基金会、莉莉安、Marlow's 小馆等捐赠者排在一起）。身家很高或穿得很体面的人去排队领饭，旁边的人会侧目，这也会被记住。艾琳周日、玛格丽特周二会来帮忙，Ben 周一把一周的饭菜送过来，老周常在这里吃午饭。
- **旧码头夜市**（每天 18:00 到凌晨一点，周五、周六到两点）：五个摊位（炒档、烤串、糖水、旧书半价、杂货），只收现金，十块钱以内吃饱；白天摊子用油布盖着，摊主不在，晚上灯笼亮起来、摊主出摊。还有一位看相先生（20 G），他说的都是一个眼尖的陌生人看得出、听得到的事：你最近在赌场的输赢、有没有东西当在当铺、穿着、熬夜的黑眼圈、身上的酒味……他不会改变任何运气。老周、汤米（他休息的晚上在这里弹琴）、丹尼尔和琪琪会来这里吃宵夜。
- **7 号码头零工**：每天 05:30–09:00 工头在码头招人，卸一船货 8 小时，时薪 15 G（周六 18 G），当场结现金，周日不开工。喝了酒、太累、没睡够或身体不好会被拒绝；和正式工作的班次冲突时会提醒你（不去上班照样记缺勤）。老周以前是这里的班长，早上常来看看。

### 灰港大酒店与周日拍卖会

联合广场边的灰港大酒店可以进去了：大堂（前台、立柱、水晶灯、钢琴）、大堂吧和楼上的宴会厅。

- **大堂吧**：英式下午茶（三层点心架，88 G）、大吉岭红茶、手冲咖啡、歌剧院蛋糕和香槟。莉莉安周四下午、索菲亚周三晚上、伊莎贝拉周六下午会来这里坐坐。
- **灰港拍卖行**每周一出新图录：五件拍品（三幅油画，分新锐 / 成名 / 偶尔一位已故名家，和两件古董腕表、珍稀烈酒、瓷器、珍本书或玉器），同一局游戏同一周内容固定。画都是按拍品的种子程序化绘制的像素画（风景、海景、静物、肖像、抽象、城市夜景各有画法，名家的笔触更细），周六 10:00 起在宴会厅的画架上预展，画架上挂的就是图录里的那几幅；图录给出估价，保留价不公开。
- **周日 15:00 现场拍卖**：在拍卖台登记领号牌（银行存款至少 5,000 G），每件拍品 12 分钟。英式公开竞价，按拍卖行的加价档位一档档往上叫；每件拍品有两到四位举号牌的匿名买家，有时还有一位电话委托，加上当天在场的熟客（莉莉安偏爱肖像、静物、玉器和瓷器，亚历山大偏爱海景、腕表、烈酒和古籍，索菲亚出价大多不超过估值，看中的是抽象画、夜景和腕表），每人心里都有自己的上限，越接近上限越犹豫；出价低于保留价时拍卖师代委托人叫价到差一档；没人再举牌就叫「一次、两次」，第三次落槌。你随时可以举牌（存款不够付「落槌价 + 15% 买家佣金」时按钮不可用），也可以「不跟了」直接看结果。没来的人那一场照样拍完，结果写进成交记录。
- **你的藏品**：拍到的东西按拍卖行的参考市值计入净资产（买入价含佣金，所以刚买下时一般是亏的），参考市值每周一按市场重新评估：新锐艺术家波动最大，偶尔会突然被藏家追捧或无人问津（会收到拍卖行的短信），已故名家最稳，烈酒稳步升值。可以委托拍卖：周六预展前委托的进本周图录，之后的排到下周；成交后扣除 10% 佣金打到银行账户，流拍退回。家里墙上有空的地方会挂上你拍到的画（会避开窗户和其他挂件），也会提高住处的体面度。家里电脑上有「拍卖行」程序，可以看图录、藏品和成交记录，在家里委托。
- 在拍卖会上拍下大件会被在场的人看见；被你抢走心头好的熟客会记住这件事，见面时会提起。

### 灰港游艇会

河滨步道东侧、灰港大酒店对面的浮动码头：码头办公室、四个泊位（港湾游船、游艇会自有的帆船「信天翁号」、你的泊位、惠特莫尔家的游艇）。走上码头，界面会换成海军蓝和白帆布的样式。

- **港湾游船**：每天 11:00、14:00、17:00、19:30 四班（夜游 90 G，其余 60 G），开船前半小时开始登船，在船边买票上船，现金、银行卡都行。游船按时刻表真的离港、90 分钟后回港，站在码头上能看见它鸣笛开走、再开回来。
- **包船出海**：信天翁号连船长和船员包 3 小时（3,200 G，10:00 / 14:00 / 18:00 出发），最多带 3 位朋友。只能约认识、熟悉并且对你有好感的人，每个人按自己的性格和处境回答：丹尼尔、琪琪、汤米等人会来，玛格丽特晕船，维克多、娜塔莎、杰克要上班，Ben 只有店里休息的周一能来，亚历山大要看和你的交情。答应的人会在开船前从各自所在的地方走到码头等你，出发前一小时游艇会发短信提醒。提前上船要在甲板上等到开船；有人还在路上你就出发，TA 会扑空并记住；你没去，客人在码头等满一小时就走，也会记住。三小时以前取消退 80%，之后不退。
- **自己的游艇**：海鸥号（Seagull 42 帆船，1,280,000 G，最多 4 位客人）或极光号（Aurora 68 机动游艇，4,600,000 G，最多 8 位客人），从银行账户付款，停在 C 泊位。每月 1 日出泊位和船员的账单（14,000 / 38,000 G），每次出海另付燃油；8:00–20:00 可以一个人出海两小时，也可以约朋友上船。按买价的七成计入净资产，交给经纪人卖掉时再扣 5% 佣金。买游艇的时候在场的人会看见。
- **出海**：你走到船边，在码头等着的朋友跟着一个个走上甲板，鸣笛，船驶离码头开出画面；海上的几个小时在三张明信片里过去，明信片是按这次出海的时间、天色、船型和同行的人程序化绘制的像素画（离港时回望灰港的天际线、灯塔边的海面、回港时的码头；汤米的吉他、琪琪的相机、Ben 的点心会出现在甲板上），配上朋友们在船上说的话；然后船开回泊位，大家下船，在码头上待一会儿再各自离开。同行的朋友好感上升，会把这次出海说出去，见面时也会提起；你自己的心情、压力和社交都会好转。
- 亚历山大周六上午常在自家的船边。码头管理员和登船时的船员都可以搭话。城市地图上标出了游艇会、夜市和 7 号码头，可以直接打车过去。

### 白石湾：海湾对面的小镇

游艇会南边是去白石湾的渡轮码头。白石湾在海湾对面，是一张新的地图：北边是渡轮码头、渔港和码头上的鱼市，西边岬角上是灯塔，中间是渔村，南边是公共海滩，东头的岬角上是度假酒店，酒店的无边泳池和私人海滩在树篱后面，只对住客开放。穷人的白石湾和富人的白石湾就隔着这道树篱：一边是跟渔船出海一天挣 240 G 的人，一边是一晚 2,600 G 的灯塔套房。

- **渡轮**：只有一条船来回跑。灰港 7:30、10:00、13:00、16:00、19:00 开，白石湾 8:30、11:00、14:00、17:00、20:00 开回来，单程 40 分钟；开船前 20 分钟检票，开船后 2 分钟停止登船，夜里船停在灰港。普通舱 25 G，头等舱 80 G（含一杯咖啡，心情和压力恢复得多一些），在售票亭或船边买票，现金、刷卡都行。船不在码头时码头上看不到它；站在码头附近，看得见它靠岸和鸣笛离港。上船的过场和游艇会一样：你走上甲板，鸣笛，船开出画面；海上的 40 分钟是一张按时间和天色画的明信片（去程是白石湾的村子、度假酒店和灯塔，回程是灰港的天际线）；到了对岸，船带着你开进码头，你走下船。末班船错过了就只能在岛上过夜。
- **同一条船上的人**：去白石湾的 NPC 先走到渡轮码头，在码头上等时刻表上的下一班船，坐那一班过海，到了再走到要去的地方，回来也一样，路上和码头上都看得见他们。日程是按船期排的：老周周三坐 7:30 的船过去下棋，琪琪周日去海滩，索菲亚周日去度假酒店吃早午餐，莉莉安周六去酒店的泳池，汤米周一在海滩小屋边弹琴（每次都有一定几率不去）。和他们坐同一班船时，明信片的甲板上会有琪琪的相机、汤米的吉他或莉莉安的遮阳帽，你认识的人会写在卡片下面。
- **渔港**：合作社的渔船周一到周六 5:30 出海、14:30 回港，礼拜天不出海；地图上的渔船跟着出海、回港。每天 4:30–5:30 船老大在码头招人：跟船出海拉一天网（14:30 回港），当场结 240 G 现金，再给一条鱼带回家（够做 3 顿饭）。喝了酒、太累或没睡够会被拒绝，和正式工作的班次冲突时会提醒你；第一次出海多半会晕船。在场的熟人会记住你去打渔工。渔船回港以后，码头上的鱼市开到 18:00（礼拜天没有），卖海鱼和花蟹，只收现金。
- **老船长食堂**（6:00–20:00，只收现金）：海鲜粥、炸鱼饭、蒜蓉蒸扇贝、海鲜大拼盘。
- **住一晚**：海鸥民宿一晚 120 G（床不太好睡）；白石湾度假酒店的海景房 980 G、灯塔套房 2,600 G（岛上最好睡的床）。在前台办理入住，房间留到第二天 11:00，同时只能订一间，只能睡自己订的那张床。酒店住客每天早上 7:00–10:30 可以在餐厅吃一次自助早餐，刷房卡进客房区，从花园门进无边泳池和住客海滩（7:00–22:00）；不是住客的人会被客气地拦在门外。在酒店订房会被在场的人看见。酒店里的灯塔海景餐厅（芝士焗龙虾、主厨海鲜套餐、香槟）谁都可以去。
- **公共海滩**：救生员 9:00–18:00 值班，只有这段时间可以下海游泳（40 分钟，喝了酒不行）、租躺椅和遮阳伞（两小时 30 G，只收现金）。海滩小屋 10:00–23:00 卖冰椰子、啤酒、烤鱿鱼和莫吉托。
- **灯塔岬**：在灯塔下站一会儿，白天看得见对岸的灰港和来回的渡轮，晚上是灯塔扫过海面的光。
- 岛上没有出租车和公交。在岛上打开地图看到的是白石湾的地图，标出各个地方和回灰港的船期。渡轮船员、灯塔看守、船老大、鱼贩、救生员、小屋老板、老船长和民宿老板娘都可以搭话。岛上有自己的白天和夜晚配乐。

### 天气

每天的天气由季节的概率和这局游戏的种子决定，同一个存档每次读出来都一样；新生活的第一天总是晴天。春天多雨、多晨雾，夏天会来风暴，冬天多阴天和雾，一个冬天会下几回雪。

- **雨**：一天里有一段时间下雨，多在下午到夜里，可能下过午夜，雨有大有小。室外看得见雨丝落下、在地上溅起水花，天色变灰、建筑的影子变淡；夜里的雨丝在路灯下发亮。人行道、广场和路面上积起一个个水洼（总在同样几处低洼的地方），下雨时水洼里不停泛开一圈圈涟漪；雨停后地面要三个小时左右才干，水洼慢慢淡去。在室内，窗玻璃外的天是灰的，雨点挂在玻璃上，过一会儿顺着玻璃流下去。街上的行人少一半，大多撑着伞，没伞的人走得快。NPC 不再去公园的长椅、球场、海滩和街头卖艺（夜市的凳子在雨棚下，照去），雨停了才回来。下雨时救生员收旗：不能租躺椅、不能下海，度假酒店的住客海滩也收了（泳池照开）；篮球场打不了，长椅湿透了坐不了。
- **伞**：便利店卖折叠伞（15 G），带在身上，下雨天走在街上会自己撑起来。没有伞在雨里走上十来分钟（只算你自己在街上走的时间，打车、上班、睡觉不算）就会淋透：之后几个小时心情变差，天冷时还会着凉、掉一点健康。风暴天有伞也只能挡一点。
- **风暴**：一整天大风大雨，雨斜着打下来，天暗得路灯白天也亮着，时不时一道闪电，过一会儿传来雷声。渡轮全天停航（船拴在灰港码头，下一班要等风暴过去），渔船不出海、鱼市不开，港湾游船停航，游艇会不出船（已经约好的出海会全额退款并通知客人），7 号码头停工，夜市不出摊，海滩、泳池和住客海滩都关闭；NPC 不出门，也不去岛上。前一天 18:00 灰港气象台会发短信预警，人在白石湾时还会提醒你末班船的时间。
- **雪**：只在冬天、天冷的日子下（最高气温不超过 4°），大约每十几个冬日一回。雪花一边飘一边左右摇摆，下雪没有声音。雪先落在草地、花园和沙滩上，一块一块地白起来，然后是人行道和广场，下得久了整片地面都白了；马路上车来车往，只是一层灰色的雪泥，车辙里露出底下的沥青，路口没有车辙；水面、泳池和红毯上不积雪。屋顶比街面冷，最先变白，屋顶上的女儿墙、机房和天窗在雪里还看得出轮廓。雪停以后，白天气温在零度以上的话大约八个小时化完，化雪时地上湿漉漉的、会积水；一直在零度以下的话要一天多才化。地上有雪时天色比平常的阴天亮。下雪时和下雨一样：海滩、球场关闭，NPC 不在室外闲坐，路人撑伞；没有伞在雪里走久了，雪落了一身化成水渗进衣领，心情变差、掉一点健康。在室内能从窗户看到雪花飘过，窗台上积起一道白。路人会聊起下雪和路滑。
- **雾**：雾天的早上海湾起雾，8 点到 11 点之间散去；雾里一片灰白，一团团的雾慢慢飘过，在海边听得到雾笛。**多云**的日子天色暗一些，不下雨。
- 时钟旁边显示现在的天气和气温（在没有窗户的赌场大厅里看不到）；手机「日程」里有今天和之后两天的预报：天气、气温、什么时候下雨、哪些地方停航。路人、渡轮船员、船老大、救生员和游船船员说的话也跟着天气变。
- 天气的声音也只用有音高的音色：雨声是许多极短的高音「水滴」叠成的沙沙声，在室内听到的是闷在屋顶和窗外的雨；雷声是几个低音一起滚动、慢慢散去；雾笛是两个低沉的簧音。赌场大厅里听不到外面的天气，楼上的天穹层隔着窗户听得到。

### 时间与生活
- 完整的时间系统：分钟、小时、日期、星期、月份（28 天）、季节；睡觉时快进时间。
- 玩家状态：体力、饥饿、睡眠、压力、情绪、自信、冲动、社交、健康、醉意。它们影响移动速度、工作效率和对话，**从不影响任何赌局概率**；体力或健康耗尽会晕倒（有医疗费和其他后果）。
- 吃饭（在家做饭便宜，外食贵）、看书提升技能、看电视、弹琴、在篮球场运动、坐在长椅上休息。
- 账单：房租、水电、手机、保险、贷款月供；自动扣款或手动付款；逾期产生滞纳金并影响信用分；长期欠租会被赶出公寓。

### 日常的动作

做日常小事时，场景里会演出对应的动作。播放时时钟停住，演的只是真实发生的事：买了什么、取了多少钱、睡了多久。

- **睡觉**：你躺到床上，枕头上露出闭着眼的头，屏幕暗下去，左上角的时钟一路走过你睡的那几个小时（睡眠是分几步真正推进的），然后你从床边起来。
- **上班**：打卡以后，时钟快进走完这个班，你在工位上忙着（头上冒出「…」），下班时弹出这个班的结算。闪送零工也一样。
- **ATM**：银行卡插进去。取钱时钞票吐到你手里，存钱时钞票塞进去，最后卡退出来。
- **点单和购物**：店员说「请慢用」或「谢谢惠顾」，你买的东西从柜台递到你手里，用的是各自的像素图标。当场吃喝的，你会转过身吃几口、喝几口，头上冒出饭碗、咖啡或酒杯；带走的东西装进纸袋。
- **在家**：做饭时灶台冒热气，然后你端起盘子吃；冰箱里拿的东西直接吃。看电视时屏幕的光映在你身上，读书时手里在翻书，换了衣服身边闪一下。
- **钢琴和篮球场**：你坐到琴前，琴上飘起音符，同时响起一小段琴声。在篮球场上运几下球，再朝最近的篮筐投一个。
- **出租车、开车和公交**：在马路边打车、开自己的车，或在公交站上车时，车会开过来停下，你上车，车开走；到了另一头，附近有马路的话，车开过来停下，你下车。出租车是黄色的，公交车是绿白两色。骑自行车没有这一段。
- **白石湾**：租了躺椅，你就躺在遮阳伞下，时钟走过那两个小时；下海或在酒店泳池里游泳时，只露出头和肩膀，周围一圈水波，来回游着；跟船出海时画面暗下去，时钟走过海上的一天，然后你回到码头。
- **码头、食堂和自己的店**：在 7 号码头卸货的八个小时里，你扛着木箱沿着码头来回走，时钟跟着走完这一天；在社区食堂帮忙时，你站到打饭窗口后面、负责的阿姨旁边，一碗碗饭菜从窗口递出去；在自己的店里看店时，你站在柜台后面，一个个纸袋递给客人。分步走完的结果和一次走完完全一样。
- **赌场兑换处**：换筹码时，筹码一摞摞推到你面前；兑回现金时，筹码收进窗口，钞票递出来。银行柜员会先打招呼再办业务。站在窗边或望远镜前，眼前会闪起星光。
- NPC 正在做的事也会不时出现在头顶：吃饭的碗、咖啡馆里的咖啡、酒吧里的酒杯、逛街的购物袋（卖唱时的音符原来就有）。
- 新加的音效（琴声、运球、翻页、锅里的噼啪声）也是有音高的合成音，没有噪声。

### 经济与职业
- 现金 / 银行存款 / 筹码三个账户，整数最小货币单位（1 G = 100），每笔交易都有可追溯流水；系统性的资金守恒校验。
- 净资产 = 资产 − 负债：资产包括证券、房产市价、车辆、贵重物品、别人欠你的钱；负债包括贷款与未付账单。
- 7 份工作（行政文员、咖啡师、服务员、调酒师、赌场荷官、投资分析师、快递零工）：班次、迟到 / 缺勤 / 警告 / 解雇、表现评分、升职、发薪日、小费。
- 银行：柜台存取款、ATM（每日限额与手续费）、个人贷款（按信用分定价、按收入核定额度）、随借 App（高利贷，成本明示）、提前还款、违约。
- 住房：6 档住宅的租赁、全款购买、按揭购买（20% 首付）、出售（5% 中介费）、搬家；房价跟随房地产指数波动；家具影响舒适度。
- **家具**：电脑上的家居商城下单后送货上门，家具真的出现在家里：电视、沙发、立式钢琴、跑步机和绿植要自己摆——在「物品 → 家具」或商城里点「摆放」，家具的虚影跟着方向键或鼠标在地上移动，能放的地方是绿色、不能放的是红色（不能压在墙上和别的东西上，不能堵门、挡床边或者把屋里任何东西隔开），按 R 转向（沙发、电视、钢琴和跑步机可以朝房间、朝左或朝右摆，转过来以后占的格子跟着变，靠着侧墙也放得下；绿植不用转），按 E 或点击放下，Esc 或右键取消；摆好的东西可以挪位置、收起来，挪的时候保持原来的朝向。电视、钢琴和跑步机摆好后就能用（跑步机在家里跑，下雨也不怕）。手工定制大床会换掉原来的床（放得下的话），当代艺术画作挂在墙上。搬家时家具跟着你走，新家放不下的进储藏室（不计入舒适度和体面），有空位再搬回来。
- **装修**：买下的房子可以在电脑的家居商城里请装修队换地板和墙面：地板换掉家里面积最大的那一种（厨房、卫生间的瓷砖和别处的地毯不动），有地毯、瓷砖、各种木地板、拼花地板和大理石十二种；墙面有乳胶漆、墙纸、红砖、清水混凝土、木饰面、护墙板、锦缎墙布和大理石十二种。按这套房子要换的地板块数和墙面块数计价，另加 600 G 上门费，付完钱第二天收工，家具不动。好材料让家里更体面（大理石地板、锦缎墙布这一类加得多），但不提高房子的估价；卖掉房子时装修留给买家。租来的房子不能装修。
- 证券市场：指数基金、债券、个股、黄金、加密资产，按几何布朗运动加市场冲击逐日变化，周末休市。
- 商店：食品、杂货、书、礼物、服装（影响外在体面度）、奢侈品、车辆、家具网购；子午线会所会员与 Lumière 餐厅预订。

- **扑克室的常客**：有几位有名有姓的人也来打扑克，各按自己的日程和打法：索菲亚周四晚上在 5/10 桌打得很紧（她说扑克不是跟赌场对赌），亚历山大周三深夜在 5/10 桌打得很凶，汤米周二夜里在 1/2 桌什么牌都想看翻牌，丹尼尔周日晚上在 1/2 桌，一输就上头（每次都有一定几率不来）。他们先在扑克室的围栏边等位，有空位（或者有陌生人让座，但给你留的那个座位不会被占）就坐下，从自己的钱里拿一部分买入；桌上的筹码、手里的钱和留在家里的钱加起来始终就是他们的全部财产，输光或赢够了就起身回家，夜深了也会走，你离开赌场时他们也散场。在牌桌特写里看得到他们的脸，知道名字的就写着名字；在他们的座位边按 E 搭话，他们会聊眼前这局牌。
- **周日扑克锦标赛**：每周日 17:00 起在扑克室门口的告示牌报名，19:00 在 1/2 桌开赛（这一晚 1/2 桌的现金局停开）。六人单桌：买入 200 G 加 20 G 服务费，每人 3,000 锦标赛筹码（只在比赛里用，不能兑换、不能加买），盲注从 25/50 开始、每 6 手升一级，输光就出局，最后两名分全部买入（冠军 780 G、亚军 420 G，现金当场付）。扑克室的常客手头宽裕、又有兴致时会报名，用的是他们自己的钱；空位由散客补齐。在桌上打和在现金桌一样（同一套发牌、下注、边池和牌型规则），筹码显示为不带 G 的数字，荷官报级别、下一手自动发；锦标赛桌的时钟走得比现金桌慢（一手大约两三分钟，一场通常两个多小时）。你离开座位（离桌、走开、离开赌场或者没来）时比赛照常进行，每隔几分钟打一手，你的牌自动弃掉，盲注照付；出局后可以留下旁观。赌场大厅里能看到选手坐在 1/2 桌边，出局的人起身离开。名次、奖金和往期结果都在告示牌上，比赛结果记入赌场战绩和日志；你淘汰的常客会记住，你夺冠的消息会传开。周六傍晚，打过扑克或常来赌场的人会收到赌场的提醒短信。NPC 牌手筹码不足十个大盲时只会全下或弃牌。

### NPC 与社会
- 17 位有名有姓的 NPC（如咖啡师艾琳、VIP 客户经理维克多、航运继承人亚历山大、投资顾问索菲亚、发小丹尼尔……），各自有年龄、职业、财务状况、居住区域、日程、性格特质、目标、社交圈、对金钱与赌博的态度。
- NPC 按日程在城市中通勤（沿人行道寻路）、在各自地点工作、喝酒、运动、赌博；他们的财务每天变化，也可能陷入危机。
- 8 维关系：好感、信任、尊重、熟悉、吸引、依赖、嫉妒、畏惧；不同 NPC 对同一行为的权重不同（有人在意你的人品，有人在意你的钱包）。
- 记忆：每段记忆带时间、重要性、来源（亲眼所见 / 你亲口说的 / 传闻）、可信度，并随时间衰减；NPC 不会凭空知道你的银行余额，只能通过观察、交谈、传闻或职业渠道（银行信贷专员能看到你的银行记录）了解你。
- 传闻沿 NPC 之间的社交关系传播，并可能被夸大或失真（金额越传越大、可信度越传越低）；说谎会在信息矛盾时被识破。
- NPC 之间会真的碰面交谈：同一时间在同一地点（室外要离得够近）的熟人会停下来寒暄、在酒吧碰杯、安慰陷入困境的朋友、因为脾气和积怨吵起来，或者把听来的关于你的事讲给对方听——传闻就是这样当面传开的。谈话会改变他们彼此的关系和情绪；发生在你身边时，一方会走过去（对柜台后上班的人则隔着柜台说话），两人用对话气泡交谈；你离得够近还能听见他们在议论你，这会记进日志。
- **他们之间**：人际面板的「他们之间」一页把你亲眼见过的来往画成一张网：只有你知道名字的人，只有你看到过他们在一起（同一间屋子里，或者室外离你不远）的那一对；线的颜色是你上次见到他们时两人的远近（很亲近 / 熟络 / 认识 / 不太对付，吵过架的画成红色虚线），看不到的时候他们关系怎么变了，这张网不会知道。点一个人的名字，看 TA 和谁走得近、见过几次、上次在哪里做什么；下面列着你看到的最近几十件事（谁和谁在哪里碰杯、吵架、安慰、说别人的事）。每个人的资料页里也有「你见过 TA 和谁在一起」。关于你的传闻正是沿着这些关系传开的。
- **朋友之间的钱**：NPC 手头紧（欠债太多，或者快没钱了）的时候，会向最亲近、手上有余钱的朋友开口借——心软、讲义气的人更容易答应，谨慎、看重钱的人少借，自己还欠着钱的人不借，真正有钱的人也不向朋友借。借的钱说好两周还，之后从自己用不完的钱里一点点还上，还清了两人更亲近；过了日子还不上，借钱的那一方每天都更介意一点，两人碰面时会提起这笔钱，脾气急的会当场吵起来（你在旁边能看到、听到，人际网里会记下「为了借钱的事吵了一架」）；拖得太久，借出去的人就不再指望了，两人的关系也伤了。熟悉的人会跟你说起谁欠了 TA 钱、或者 TA 欠了谁的钱，知道以后，你可以在对话里替欠钱的人把剩下的钱还上：借出去的人拿回钱，两人和好，欠钱的人会记住你帮了 TA。钱只在他们之间流动，不会凭空多出来或消失。
- 动态对话：内容由性格、关系、已知事实、情绪、场景和近期事件共同决定，同一 NPC 会避免重复台词；预留了可选的外部文本生成接口，核心逻辑不依赖它。
- 半身像：对话框左侧是比对话框高出一截的像素半身像（64×80 像素，按 2 倍显示），每位有名有姓的 NPC 都有自己的眼型、瞳色、眉形、鼻子、脸型、年龄纹路、妆容、雀斑、痣、胡子、眼镜和首饰，衣着与地图上的小人一致；背景色跟着所在场所变。表情有 9 种（平静、微笑、大笑、得意、皱眉、难过、担心、惊讶、生气），由对方实际的反应决定：这句话让 TA 对你的观感变好还是变坏、TA 提起的是你赢钱还是你输钱、TA 本来对你的态度——而不是随机换脸；说话时嘴会动，隔几秒眨一次眼。人际面板、手机联系人、个人统计页和角色创建也用同一套头像。立绘是程序生成的像素画，不是手绘或写实插画。
- 按 E 搭话时，对方会停下、转身面向你，聊天期间不会按日程走开（路上被叫住的人，剩下的路程也会顺延）；聊完稍等一会儿才回到原来的安排。对你好感很低（或者天性就讨厌你这类人）的人有一定概率不想理你，好感越低越可能被拒绝，但不会每次都拒绝。

- **天气**：同一局游戏的天气每次都一样（读档后也一样），不同的局不一样；两年里各季节各种天气的比例符合设定的概率（夏天的风暴远多于冬天，冬天的雾多于夏天），第一天总是晴天；雨只在它的时段里下、可以下过午夜，风暴下一整天，雾在早上散去；夏天比冬天暖、下午比凌晨暖；风暴天渡轮全天拴在灰港、前一晚出发去岛上的人要等风暴过去的第一班船，渔船、鱼市、码头的活、夜市、游船、游艇会都停，海滩和泳池都关，已经约好的出海全额退款并发短信；前一天 18:00 只发一条预警；风暴天没有 NPC 在室外或岛上，晴天同一周有；雨天海滩、住客海滩和球场关闭（泳池照开），没人在室外闲坐、运动或卖艺，但夜市照常有人坐；没伞在街上走十来分钟会淋透，有伞不会，跳过的时间和室内不算，风暴天有伞也会淋湿一点；便利店卖伞；室外有雨声、室内是闷住的雨声、赌场大厅里没有，雾笛只在海边的雾里响，雨夜听不到虫鸣；雪只在冬天的冷天下，下雪时地上的雪越积越厚、雪停后化掉（零度以上快、以下慢），下雪不算积水、化雪才算，雨后地面湿三个小时，晴天一直是干的，雪里没伞会落一身雪，下雪没有雨声；雪只落在草地、路面这类地面上，不落在水面、泳池和红毯上；水洼每次都在同样的位置，只在露天的铺装地面上，室内没有。
- **周日锦标赛**：周日 17:00 开放报名，常客用自己的钱报名、只在付得起时报名，别的日子不开；报名扣买入加服务费、不能重复报名、可以退报全额退款；19:00 散客补满六人、每人筹码相同，1/2 桌的现金局停开；离开座位时你只会弃牌或过牌；比赛中的筹码总数始终不变，盲注按手数升级，六个名次各不相同，冠亚军奖金加起来正好是全部买入，你的奖金记在流水里；在桌上打的手牌流程、一手打到一半被带离赌场时自动弃牌；比赛进行中存档读档后结果完全一致；旧存档没有锦标赛；筹码少于十个大盲时 NPC 只会全下或弃牌。
- **朋友之间的钱**：手头紧的人向亲近、有余钱的朋友借到钱，借出的和借到的分毫不差，第二天不会再借；不亲近或没有余钱的人不会被借；有了余钱就还上，还清后关系更好，所有人的钱加起来不变；过期后关系每天变差，两人碰面时由借出的一方提起这笔钱、有时吵起来，你看到后就知道了这笔钱，人际网写着为借钱吵架；拖到期限之后借出的人放弃；你可以替人还钱：借出的人拿到剩下的钱，你的钱少了同样多，欠钱的人记住这件事，还过的钱不能再还；旧存档从没有借贷开始。
- **家具**：不能摆在墙上、别的东西上和门口；每个允许的位置放下之后，屋里的每样东西仍然走得到；每处住宅都放得下每一件能摆的家具（合租房至少放得下绿植）；定制大床换掉旧床后屋里照样都走得到，原地图不受影响；买来的电视摆下后在屋里、挡住它的格子、可以用，挪位置时它原来的位置不算占用，放不下的地方被拒绝且什么都不变，收起后回到「还没摆」；跑步机下雨也能用、球场不能；搬到合租房时放不下的进储藏室、旧的摆放随旧家留下，储藏室里有的不能再买一件，搬进大房子后全部回到家里；旧存档得到空的摆放和储藏室。转向：沙发、电视、钢琴、跑步机能朝左朝右（侧面图，朝右是镜像），转过来的长家具占的格子横竖对调，绿植不能转；转过来摆好的沙发占它的格子、读档后还是朝那边，转过来的电视照样能看。装修：租的房子不行；报价等于上门费加每块地板和墙面的价钱，付款走流水且资金守恒；第二天才换好、换好之前不能再叫一次；换的只是面积最大的那种地板和那种墙面，挡路的格子一格不变，体面度按材料增加；装修跟着房子保存，卖掉房子后清掉；每处住宅换任何地板和墙面都只用真实的地块、门口照样走得进来。
- **扑克常客**：四位常客各有一个打牌的晚上；坐下时的买入在本桌限额之内、按自己的打法打；一小时的牌局里，每两手之间他们的钱都正好等于手里、桌上和留在家里的总和；夜里散场、和你一起离开赌场时，筹码一分不差地回到自己的钱里；围栏上的等位处都走得到。
- **人际网**：只记下你在场看到的碰面（同一间屋子，或室外离你不远的地方），别处的不记；网上只有你知道名字的人，知道名字后那一对才出现；线上的远近是你上次看到时的样子，之后看不到的变化不会改变它；吵过架而本来就不亲近的一对显示为不太对付；只保留最近 80 件事；旧存档从空白开始。
- **NPC 碰面**：只有真正同处一地（室外看距离）的熟人才会交谈、每对每天最多一次；当面八卦把故事（经过转述）传给对方且不会重复讲；争吵降低、寒暄与安慰提高彼此关系；困境中的朋友会被安慰；偷听只记录一次；结果可复现并能随存档保存；一个月的模拟中关系值始终在合理范围内。

除单元测试外，开发过程中用无头浏览器（Playwright）脚本实际走完了这些流程：创建角色、走出家门、和 NPC 对话、上一整班、在兑换台换筹码、走到赌桌前入座、打 21 点 / 百家乐 / 轮盘、走进扑克室按 E 入座、买入、用键盘打多手德州扑克（含全下与摊牌）、弃牌后离桌再重新入座、保存 → 刷新页面 → 读档后状态一致（包括在一手牌中途读档后继续这一手）。

## 工程结构

```
fortune-ruin/
  src/
    core/        GameCore（时钟与系统装配）、状态定义、可序列化随机数、金额、日历、事件总线、新游戏
    casino/      BlackjackEngine / BaccaratEngine / RouletteEngine / PokerEngine（纯规则引擎）、
                 牌靴、基本策略、赌客 AI、扑克 NPC（pokerAI）、桌台配置、轮盘布局与转盘运动学、百家乐路单
    systems/     Economy / Player / Inventory / Housing / Career / Casino / Market /
                 NPCManager / Social（关系、记忆、传闻）/ Encounter（NPC 之间的碰面）/
                 Story（多步骤故事线）/ Dialogue / Event / Phone / Wealth / Services / Save /
                 Weather（每天的天气、风暴与雨的规则）/ NpcLending（NPC 之间的借贷）/
                 Tournament（周日扑克锦标赛）
    data/        NPC、物品、工作、住房、地点、台词素材
    world/       WorldScene（地图、玩家控制、互动、光照）、NPC 导演、城市人群、赌场大厅、天气效果（雨、雪、雾、闪电、地上的积雪和水洼、屋顶的雪、室内窗户上的雨）、地图数据
    tables/      21 点 / 百家乐 / 轮盘 / 德州扑克桌与周日锦标赛的特写场景（只负责动画，结算全部由引擎完成）
```

需求里列出的模块与代码的对应关系：GameCore → `core/GameCore.ts`；WorldManager / PlayerController → `world/WorldScene.ts` 与 `world/maps/*`；TimeSystem → `core/calendar.ts` + GameCore 时钟；EconomySystem、CasinoManager、NPCManager、DialogueEngine、EventManager、InventorySystem、HousingSystem、CareerSystem、SaveManager → `systems/` 下同名文件；BlackjackEngine / BaccaratEngine / RouletteEngine / PokerEngine → `casino/`；NPCMemorySystem 与 RelationshipSystem → `systems/SocialSystem.ts`；UIManager → `ui/store.ts` 与 `ui/App.tsx`。

设计约束：规则引擎与动画、输入完全解耦（引擎返回事件列表，场景只负责播放）；关系模型与具体台词解耦；金额全部用整数最小单位；所有随机结果来自可设种子、可序列化的 xoshiro128** 随机数；统一的事件总线处理财富、关系与剧情事件。
