# 夜色筹码：Fortune & Ruin

一款 2D 俯视角开放世界「赌场人生」模拟游戏。你住在港口城市 **灰港（Greyhaven）**，可以上班、租房买房、交朋友、投资，也可以走进灰港大赌场，在完全按照公开规则运行的牌桌上下注——然后亲身体会财富的起伏如何改变你的生活，以及别人看你的眼光。

> **所有赌注、筹码与财富均为纯虚拟游戏货币。** 本游戏不提供任何真钱投注、充值、兑换或提现，游戏内容不构成任何投资或博彩建议。

---

## 快速开始

需要 Node.js 18+（开发时使用 Node 22）。在仓库根目录或 `fortune-ruin/` 目录下执行：

```bash
npm install
npm run dev        # 启动开发服务器，浏览器打开 http://localhost:5173
npm test           # 运行全部单元测试（Vitest）
npm run build      # 类型检查 + 生产构建，输出到 fortune-ruin/dist
npm run preview    # 预览生产构建
```

游戏完全离线运行：所有像素美术、音效和音乐都在运行时由代码生成，没有任何外部资源请求，也不依赖付费 AI 服务。界面文字使用系统自带的中文字体。

### 单文件版（不用安装任何东西）

```bash
npm run build:single   # 输出 fortune-ruin/dist-single/fortune-ruin.html（约 2 MB）
```

这个 HTML 文件包含了整个游戏（代码、Phaser、React、样式）。把它复制到任何电脑上，用 Chrome / Edge / Firefox / Safari 双击打开就能玩，不需要 Node.js、不需要联网。存档保存在这台电脑的浏览器里；换电脑或换浏览器时，先在游戏的存档界面「导出」存档文件，再到新地方「导入」。

## 开局

创建角色（名字、外观、性格倾向、出身背景）后，你在第 1 年 3 月 1 日（星期一）早上 7 点于老城区的枫庭公寓醒来：

- 现金 1,000 G，银行存款 19,000 G，没有大额负债（「大学毕业生」背景带一笔助学贷款）；
- 普通出租公寓（月租 1,450 G），灰港物流的行政文员工作（9:00–17:00，月薪 4,400 G）；
- 几位朋友（发小丹尼尔、咖啡师艾琳、房东玛格丽特……），以及灰港大赌场的普通访客会员卡；
- 手机里有朋友的消息、上司的会议提醒和银行的账户概览。

## 已实现的内容

以下功能均可在游戏中实际操作，并有对应的自动化测试或实机验证（见「测试」一节）。

### 城市与世界
- 120×90 格的灰港城市地图：老城区、集市街、市中心、联合广场、河滨公园与步道、码头、山丘富人区，带门禁的富人区入口；29 栋有外立面的建筑。
- 19 个可进入的室内场景：6 档住宅（码头合租房 → 山丘庄园）、便利店、咖啡馆、餐厅、酒吧、服装店、银行、办公室、投资公司、私人会所、米其林餐厅、奢侈品店、车行，以及灰港大赌场。
- 玩家角色移动（键盘 / 点击寻路）、碰撞与转角辅助、门与场景切换（带营业时间、会员、预订、着装、员工等进入条件）。
- 昼夜系统：日出日落随季节变化，夜间路灯光圈、亮灯的窗户与霓虹，室内各自的照明。
- 街上的行人与车流（车辆会为行人停下），公交站（06:00–24:00）、出租车与私家车 / 自行车出行。

### 时间与生活
- 完整的时间系统：分钟、小时、日期、星期、月份（28 天）、季节；睡觉时快进时间。
- 玩家状态：体力、饥饿、睡眠、压力、情绪、自信、冲动、社交、健康、醉意。它们影响移动速度、工作效率和对话，**从不影响任何赌局概率**；体力或健康耗尽会晕倒（有医疗费和其他后果）。
- 吃饭（在家做饭便宜，外食贵）、看书提升技能、看电视、弹琴、在篮球场运动、坐在长椅上休息。
- 账单：房租、水电、手机、保险、贷款月供；自动扣款或手动付款；逾期产生滞纳金并影响信用分；长期欠租会被赶出公寓。

### 经济与职业
- 现金 / 银行存款 / 筹码三个账户，整数最小货币单位（1 G = 100），每笔交易都有可追溯流水；系统性的资金守恒校验。
- 净资产 = 资产 − 负债：资产包括证券、房产市价、车辆、贵重物品、别人欠你的钱；负债包括贷款与未付账单。
- 7 份工作（行政文员、咖啡师、服务员、调酒师、赌场荷官、投资分析师、快递零工）：班次、迟到 / 缺勤 / 警告 / 解雇、表现评分、升职、发薪日、小费。
- 银行：柜台存取款、ATM（每日限额与手续费）、个人贷款（按信用分定价、按收入核定额度）、随借 App（高利贷，成本明示）、提前还款、违约。
- 住房：6 档住宅的租赁、全款购买、按揭购买（20% 首付）、出售（5% 中介费）、搬家；房价跟随房地产指数波动；家具影响舒适度。
- 证券市场：指数基金、债券、个股、黄金、加密资产，按几何布朗运动加市场冲击逐日变化，周末休市。
- 商店：食品、杂货、书、礼物、服装（影响外在体面度）、奢侈品、车辆、家具网购；子午线会所会员与 Lumière 餐厅预订。

### 赌场
- 赌场大厅：安检、兑换台、ATM、21 点区、轮盘区、百家乐区、扑克室、高额投注区、VIP 私人厅、经理办公室、幸运七酒吧与休息区；赌场里不显示时钟（设置中可开启）。
- **21 点**：多副牌牌靴、切牌与烧牌、真实发牌顺序、要牌 / 停牌 / 加倍 / 分牌（含分 A 规则）/ 晚投降（部分桌）、Blackjack 3:2（欢乐桌 6:5）、庄家软 17 停牌或要牌（按桌公布）、明牌 A 时可买保险、庄家先查 Blackjack。
- **百家乐**：8 副牌、开靴烧牌、完整补牌规则表、庄赢抽 5% 佣金、和局 8:1（和局时庄闲退回）、对子 11:1、珠盘路与大路。
- **欧式轮盘**：单零 37 格，单号 / 分注 / 街注 / 三数 / 角注 / 前四 / 线注 / 打注 / 列注 / 红黑 / 单双 / 大小，高额区桌提供 La Partage；转盘动画根据引擎已经抽出的格子反算球的轨迹，**看到的结果就是结算的结果**。
- **德州扑克**（扑克室两张 6 人无限注现金桌：1/2 与 5/10）：7 张牌取最佳 5 张的完整牌型比较（含 A-2-3-4-5 顺子、踢脚、公共牌成牌平分）、按钮位与大小盲轮转（含两人单挑规则）、翻牌前 / 翻牌 / 转牌 / 河牌四轮下注与烧牌、最小加注额与「不足额全下不重新开放加注」规则、无人跟注的下注退回、主池与边池、平分底池的零头规则、公开的抽水（看到翻牌才抽 5%，有封顶）。玩家选择买入金额入座，只能在两手之间补码或离桌（弃牌后也可离桌），面前的筹码一直算在筹码账户里、但不能拿去兑现或下别的注。
- 扑克 NPC 牌手有 6 种风格：紧手、松手、激进、被动、爱诈唬、易上头（连输后打法变松变凶）；他们的决策只读取自己的两张底牌和桌面公开信息（公共牌、底池、下注、筹码量、位置），翻牌前用 Chen 公式评估起手牌，翻牌后用蒙特卡洛模拟估算胜率再结合底池赔率与性格做决定——不会偷看任何人的牌，也没有预先写好的输赢。玩家不在的扑克桌也在后台按同样的规则真实开局。
- 每张桌子的规则、限注和理论庄家优势都在桌面与信息栏中公开。
- 同桌的 NPC 赌客有各自的资金、风险偏好、策略水平、情绪和离场条件，与玩家共用同一副牌靴；其他赌桌在后台按真实规则持续开局。
- 会员制度（普通访客 / Silver / Gold / Platinum / Diamond）：按「下注额 × 公布的庄家优势」（理论损失）评级；礼遇包括酒水招待、餐饮积分、高额区与 VIP 厅资格、客户经理、信用额度（marker，是需要偿还的贷款）——**会员等级永远不改变概率**。
- 赌场的商业行为：算牌监控（下注额与真实点数的相关性会引来注意，严重时被禁止玩 21 点）、自我限制申请、员工不得在本场下注。

### NPC 与社会
- 17 位有名有姓的 NPC（如咖啡师艾琳、VIP 客户经理维克多、航运继承人亚历山大、投资顾问索菲亚、发小丹尼尔……），各自有年龄、职业、财务状况、居住区域、日程、性格特质、目标、社交圈、对金钱与赌博的态度。
- NPC 按日程在城市中通勤（沿人行道寻路）、在各自地点工作、喝酒、运动、赌博；他们的财务每天变化，也可能陷入危机。
- 8 维关系：好感、信任、尊重、熟悉、吸引、依赖、嫉妒、畏惧；不同 NPC 对同一行为的权重不同（有人在意你的人品，有人在意你的钱包）。
- 记忆：每段记忆带时间、重要性、来源（亲眼所见 / 你亲口说的 / 传闻）、可信度，并随时间衰减；NPC 不会凭空知道你的银行余额，只能通过观察、交谈、传闻或职业渠道（银行信贷专员能看到你的银行记录）了解你。
- 传闻沿 NPC 之间的社交关系传播，并可能被夸大或失真（金额越传越大、可信度越传越低）；说谎会在信息矛盾时被识破。
- NPC 之间会真的碰面交谈：同一时间在同一地点（室外要离得够近）的熟人会停下来寒暄、在酒吧碰杯、安慰陷入困境的朋友、因为脾气和积怨吵起来，或者把听来的关于你的事讲给对方听——传闻就是这样当面传开的。谈话会改变他们彼此的关系和情绪；发生在你身边时，一方会走过去（对柜台后上班的人则隔着柜台说话），两人用对话气泡交谈；你离得够近还能听见他们在议论你，这会记进日志。
- 动态对话：内容由性格、关系、已知事实、情绪、场景和近期事件共同决定，同一 NPC 会避免重复台词；预留了可选的外部文本生成接口，核心逻辑不依赖它。
- 20 多种动态事件（生日邀请、聚餐、象棋、乐队演出、篮球、朋友借钱、房东涨租、赌场贵宾邀约、朋友担心你赌博、危机时的援手、势利朋友的疏远……），带条件、概率与冷却，结果写入日志并影响关系。
- 持续数周的多步骤故事线，走向取决于你的选择、NPC 的真实财务与性格，以及运气（进行中的故事显示在日志顶部，随存档保存）：
  - **马可的赌债**：赌瘾缠身的马可开口借钱——借给他、拒绝，或者劝他收手。借出去的钱可能被他输掉；没人帮忙他会去借高利贷，追债的人找上门后你还可以替他还一部分、约他谈谈或者袖手旁观。结局包括还清欠款、一个月不进赌场的「戒赌」（他的日程真的会变）、或者车被拖走、停职两周。你自己常泡赌场时，劝他收手就没什么说服力。
  - **丹尼尔的早餐铺**：发小想把码头边的旧报亭改成早餐铺，邀你入股。投入的钱变成资产表里的一笔股份，生意每周有真实的盈亏、每四周按利润分红，遇到困难时他会请你追加投资；最后可能经营成功被他溢价买回股份、勉强维持按估值买回，或者关门清算。整体是一笔有风险、期望略为负的投资。
- 财富阶层：负债者 / 低收入 / 普通工薪 / 中产 / 富裕 / 百万富豪 / 超高净值（初始平衡方案，金额见资产面板）；分别追踪真实财富、流动财富、陌生人眼中的财富、熟人圈的估计、社会声望、赌场声望与可信度。

### 界面、存档与音频
- 主菜单、角色创建、HUD（时间、地点、现金 / 存款 / 筹码及变动、状态条）、对话、商店、兑换台、ATM、银行、电脑、手机、资产（总览 / 流水 / 趋势图）、人际、地图、日志、物品、统计（状态、技能、赌场战绩、人生轨迹）、设置。
- 存档：自动存档（每天、睡觉、回家时）+ 3 个手动存档位，带校验和与版本迁移，可导出 / 导入文件；存档包含世界时间、NPC 状态与记忆、赌桌牌局状态（包括进行中的一手牌）。
- 音频：用 Web Audio 实时合成的发牌、筹码、轮盘、结算等音效，按地点与昼夜变化的环境声，以及生成式背景音乐。

## 测试

```bash
npm test
```

自动化测试（`fortune-ruin/tests/`）覆盖：

- **21 点**：所有赔付（含 3:2 与 6:5）、庄家软 17 规则、加倍 / 分牌 / 投降 / 保险、多人同桌、牌靴完整性（不丢牌、不重复），以及 12 万手模拟的庄家优势与理论值一致。
- **百家乐**：补牌规则表穷举、8 副牌精确组合计算（庄 0.458597 / 闲 0.446247 / 和 0.095156）、各注庄家优势、15 万局蒙特卡洛。
- **轮盘**：桌面布局、每种下注形状、每个位置的回报率都是 36/37、La Partage、限注、可复现性、卡方检验；桌面点击 → 下注 → 筹码位置的往返一致；**球最终停下的格子永远等于引擎抽出的格子**。
- **德州扑克**：9 种牌型的排序与各种特殊情况、与独立的穷举评估器在 2 万手随机牌上逐一对照、主池 / 边池分配、盲注与位置（含单挑）、最小加注与不足额全下、无人跟注退回与翻牌前不抽水、全下后发完公共牌、平分底池的零头、弃牌者的盲注留在底池；3,000 手随机对局中筹码不增不减且每个座位的变化都等于「赢得 − 投入」；NPC 只能看到自己的牌（替换别人的底牌不改变它的决策）、始终做出合法动作、不同风格的入池率和激进程度确实不同；赌场层面：筹码账户逐手对账、桌上筹码不能兑现、买入范围、只能在两手之间离桌、离开赌场时自动打完并结算、牌局中途自动存档读档后继续得到相同结果。
- **经济**：初始资产、交易校验、筹码只能在赌场使用、ATM 限额、400 次随机操作后的资金守恒、赌场流水对账、贷款与违约。
- **模拟**：45 天无界面运行（需求、睡眠、上班、发薪日，上完班不会被记缺勤）。
- **长期平衡**：四种模拟的生活方式各过四个月——按时上班的人能存下钱，周末玩 21 点的人少存一些，每晚豪赌的人越输越多、最后丢了工作，不工作的人存款逐月减少；全程资金守恒。
- **反复进出赌场**：离开赌场后人群散去，牌桌上不会留下「幽灵」占座或下注，下次来仍然可以入座。
- **存档**：完整往返、读档后继续运行结果完全一致、牌局中途存读、篡改检测、存档位。
- **社会**：不同 NPC 对同一行为反应不同、危机中忠诚者与势利者的差异、谎言被识破、财富下降后友谊保留、记忆、合法的银行信息渠道、传闻传播与失真、外表带来的财富判断、对话引用传闻。
- **故事线**：马可赌债的每条分支（借钱、拒绝 → 高利贷 → 袖手旁观 → 停职；替他还债 → 一个月真的不去赌场）、劝说成功率随信任变化、过期的回复不起作用、冷却期；入股早餐铺时资金进入股份而净资产不变、每一笔分红与回购都能在流水里对上、拒绝后不会再提、故事进行中存档读档后继续完全一致。
- **NPC 碰面**：只有真正同处一地（室外看距离）的熟人才会交谈、每对每天最多一次；当面八卦把故事（经过转述）传给对方且不会重复讲；争吵降低、寒暄与安慰提高彼此关系；困境中的朋友会被安慰；偷听只记录一次；结果可复现并能随存档保存；一个月的模拟中关系值始终在合理范围内。

除单元测试外，开发过程中用无头浏览器（Playwright）脚本实际走完了这些流程：创建角色、走出家门、和 NPC 对话、上一整班、在兑换台换筹码、走到赌桌前入座、打 21 点 / 百家乐 / 轮盘、走进扑克室按 E 入座、买入、用键盘打多手德州扑克（含全下与摊牌）、弃牌后离桌再重新入座、保存 → 刷新页面 → 读档后状态一致（包括在一手牌中途读档后继续这一手）。

## 工程结构

```
fortune-ruin/
  src/
    core/        GameCore（时钟与系统装配）、状态定义、可序列化随机数、金额、日历、事件总线、新游戏
    casino/      BlackjackEngine / BaccaratEngine / RouletteEngine / PokerEngine（纯规则引擎）、
                 牌靴、基本策略、赌客 AI、扑克 NPC（pokerAI）、桌台配置、轮盘布局与转盘运动学、百家乐路单
    systems/     Economy / Player / Inventory / Housing / Career / Casino / Market /
                 NPCManager / Social（关系、记忆、传闻）/ Encounter（NPC 之间的碰面）/
                 Story（多步骤故事线）/ Dialogue / Event / Phone / Wealth / Services / Save
    data/        NPC、物品、工作、住房、地点、台词素材
    world/       WorldScene（地图、玩家控制、互动、光照）、NPC 导演、城市人群、赌场大厅、地图数据
```

需求里列出的模块与代码的对应关系：GameCore → `core/GameCore.ts`；WorldManager / PlayerController → `world/WorldScene.ts` 与 `world/maps/*`；TimeSystem → `core/calendar.ts` + GameCore 时钟；EconomySystem、CasinoManager、NPCManager、DialogueEngine、EventManager、InventorySystem、HousingSystem、CareerSystem、SaveManager → `systems/` 下同名文件；BlackjackEngine / BaccaratEngine / RouletteEngine / PokerEngine → `casino/`；NPCMemorySystem 与 RelationshipSystem → `systems/SocialSystem.ts`；UIManager → `ui/store.ts` 与 `ui/App.tsx`。

设计约束：规则引擎与动画、输入完全解耦（引擎返回事件列表，场景只负责播放）；关系模型与具体台词解耦；金额全部用整数最小单位；所有随机结果来自可设种子、可序列化的 xoshiro128** 随机数；统一的事件总线处理财富、关系与剧情事件。
