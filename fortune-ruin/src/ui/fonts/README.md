# 界面字体

`fusion-pixel-12px-zh_hans.woff2` 是 [缝合像素字体 Fusion Pixel Font](https://github.com/TakWolf/fusion-pixel-font)
（12 像素、比例模式、简体中文字形）。它以 [方舟像素字体 Ark Pixel Font](https://github.com/TakWolf/ark-pixel-font)
为基础，并用 [俐方體11號 Cubic 11](https://github.com/ACh-K/Cubic-11) 与 [Galmuri](https://github.com/quiple/galmuri)
补充字形。四者都以 SIL Open Font License 1.1 发布，许可证全文见本目录的 `OFL-*.txt`。

本项目从源码构建了这份字体文件（Fusion Pixel 版本库的 `tools.build_fonts`，Ark Pixel 2026.09.25），未修改字形。
